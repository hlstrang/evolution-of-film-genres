# The Evolution of Film Genres
### Using TMDb and IMDb datasets to analyse the evolution of film genres through the ages

## Data Source
Obtained from Kaggle, available [here.](https://www.kaggle.com/datasets/ggtejas/tmdb-imdb-merged-movies-dataset)

[License](https://creativecommons.org/licenses/by-nc-sa/4.0/)


## Aims
I intended to evaluate how specific film genres or microgenres have changed over time.

I used R to visualise trends, including number of films through the decades, profits, average ratings, etc.

I also used Random Forest models to predict which features of these films, e.g. budget, runtime, popularity, etc., were most likely to influence profit of the film.
